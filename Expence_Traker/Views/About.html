Project Overview
Project Name

Expense Tracker

Description

Expense Tracker is a simple web application that helps users manage their daily income and expenses. It provides an easy way to record transactions, organize categories, and view financial reports.

Project Features
Dashboard
Financial overview & recent stats
Income Management
Track and log incoming funds
Expense Management
Record daily spending records
Category Management
Organize & tag expenses
Reports & Analytics
Chart.js visualizations
Settings
Theme & currency preferences
Technologies Used
ASP.NET (.NET Framework) C# HTML5 CSS3 Bootstrap 5 JavaScript SQL Server (Future Database) Chart.js

Thank you for using the Expense Tracker application. This project was developed as a college assignment to demonstrate basic web development concepts using ASP.NET (.NET Framework).
